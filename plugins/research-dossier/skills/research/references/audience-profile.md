# Default audience profile

This is an editable starting point, not a universal truth.

- Language: Russian.
- Interests: business, self-development, psychology, thinking, work, money, and practical decisions.
- Desired experience: intellectually serious but clear, concrete, and emotionally legible.
- Audience tolerance: open to counterintuitive ideas when the reasoning is transparent.
- Avoid: motivational cliches, fake certainty, unexplained academic jargon, and invented success stories.
- Preferred editorial value: a useful mental model plus a memorable human or visual example.

Ask the user to revise this profile on first run and store the result as the global local audience configuration.
