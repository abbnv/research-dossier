# Generic compatibility

The portable contract is the set of Markdown skill folders under `plugins/research-dossier/skills/`. A compatible host should preserve:

- the first-run audience setup;
- local projects under `./research/<slug>/`;
- resume choice when unfinished projects exist;
- mandatory user confirmation after `working/question-map.md`;
- source links beside factual claims;
- reader-friendly evidence language, with technical source evaluation kept in `working/source-ledger.md`;
- two-pass workflow: open material collection followed by scenario synthesis;
- editorial cards that explain each important source and its scenario use;
- a recommended video structure plus alternatives after the short findings;
- exact ten wild concepts;
- Markdown-first output and optional HTML;
- explicit stopping when web search is unavailable.

The host adapter may change only installation syntax, tool names, and paths required by its own specification. If a platform lacks browsing, file writes, or HTML execution, state the limitation and provide the closest safe workflow. Never claim a source was checked when it was not accessible.

## Antigravity, Google, OpenCode

Copy the `research` skill and desired companion skills according to the host's documented skill directory convention. Keep the reference files under `research/references/` beside `SKILL.md`. Use the same project artifacts and output contract. Add a dated note here when a host's specification has been checked and behavior differs.
